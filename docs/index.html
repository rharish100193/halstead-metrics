Halstead Metrics

Halstead software-science metrics for all major programming languages. Every language uses the same classification and the same formulas.

A desktop app and a terminal app browse a source file, show the measures, and write an HTML or PDF report that explains what those measures mean.

Packages

PackageWhat it is
halstead-metricsLibrary. Tokenizes source, classifies operators and operands, and renders the HTML and PDF reports.
halstead-metrics-coreCommand-line tool. halstead <path> prints the JSON report to stdout.
halstead-metrics-tuiTerminal UI. halstead-tui browses a folder, shows the measures and highlighted source, and writes an HTML or PDF report. Requires Node 22 or newer.
DesktopDesktop application. Browse files, read the metrics, and open an HTML or PDF report. It is built from this repository and is not an npm package.

Start here

npm install -g halstead-metrics-core
halstead path/to/File.java

npm install -g halstead-metrics-tui
halstead-tui
