Command line

halstead-metrics-core prints one JSON report for a source file. It needs Node 18 or newer.

npm install -g halstead-metrics-core
halstead path/to/File.java

From a checkout of this repository:

npm run cli -- examples/Sample.java
node packages/halstead-metrics-core/index.js examples/hello.c

Exit codes

CodeWhen
1No arguments, -h, --help, or -help. Usage is printed.
2The path cannot be read.
3The file extension is not a supported language.

Stdout

Stdout is one JSON object. Counts inside _Operands and _Operators are strings. filename is the path you passed in.

{
  "Halstead": {
    "n1": 3,
    "n2": 2,
    "N1": 3,
    "N2": 2,
    "Vocabulary": 5,
    "Length": 5,
    "Estimated program length": 6.75,
    "Volume": 11.61,
    "Difficulty": 1.5,
    "Effort": 17.41,
    "Programming time": 0.97,
    "Purity ratio": 1.35,
    "_Operands": { "x": "1", "1": "1" },
    "_Operators": { "int": "1", ";": "1", "=": "1" }
  },
  "filename": "Sample.java"
}
