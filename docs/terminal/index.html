Terminal UI

halstead-tui browses a folder, shows the measures and highlighted source, and writes an HTML or PDF report. It needs Node 22 or newer.

npm install -g halstead-metrics-tui
halstead-tui

From a checkout of this repository, npm run tui starts the same program.

The screen has the same two panes as the desktop app. Files is on the left. Measures and Source are on the right.

KeyAction
Arrow keysMove through the tree
EnterOpen a file or expand a folder
uMove to the parent directory
oAsk for a path
hWrite the HTML report next to the source file
pWrite the PDF report next to the source file
[ ]Scroll the source
qQuit

A file that is not a supported language still opens in the source pane. Its metrics stay empty.
